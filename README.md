Honeybee Simulator 🐝🍯

Created by a real-life beekeeper from Coorg (Kodagu), Honeybee Simulator is a cozy beekeeping and farm management game where you build, breed, care for, and expand your own apiary. Gather materials, craft bee boxes, tend to your colonies, protect them from pests, and harvest golden honey at your own pace.

For a local preview, run `python3 -m http.server 8000` from this folder and open `http://localhost:8000/`. Some browsers block the soundtrack when the game is opened directly as a `file://` URL.
